# Code of conduct

Be respectful, constructive, and considerate in project spaces. Harassment,
discrimination, threats, and deliberately disruptive behavior are not accepted.

Project maintainers may edit or remove contributions and restrict participation
when behavior harms the community. Report conduct concerns privately through the
repository owner's GitHub profile rather than opening a public issue.

This policy is guided by the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
